# Dot Cursor

マウスカーソルを小さな**ドット**に置き換え、その後ろを**遅れて追いかけるドット**も付けられる Chrome 拡張です。

- メインのカーソルをドットにする(色と大きさを変えられます)
- 追いかけるドットを、好きな数だけ追加できます(大きさと追いかける速さを、ドットごとに設定)
- リンクやボタンの上に乗ると、追いかけるドットが拡大します(倍率を変えられます。テキスト入力欄を対象にするかも選べます)
- 設定はツールバーのポップアップから変えられ、すぐに反映されます。「すべてデフォルトに戻す」もあります

## 設定できる項目

| 項目 | 範囲 |
| --- | --- |
| メインのドットの色 | 色の選択、または RGB(0〜255) |
| メインのドットの大きさ | 4〜32 px |
| 追いかけるドットの大きさ | 4〜60 px |
| 追いかける速さ | 0.01〜1(大きいほど速い) |
| 拡大の倍率 | 1〜4 倍 |

## インストール

Chrome ウェブストアには公開していません。ソースから入れてください。

1. このリポジトリをクローンするか、zip でダウンロードして展開する(`git clone https://github.com/fatcorn753/dot_cursor`)
2. `chrome://extensions` を開き、**デベロッパーモード**をオンにする
3. **パッケージ化されていない拡張機能を読み込む**で、手順 1 のフォルダを選ぶ

## 注意

- すべてのサイト(`<all_urls>`)で動きます。ページ内に表示するドットは、このために必要な権限です。
- 保存するのは設定だけで、`chrome.storage.local` を通じて、このブラウザの中だけに置かれます。外部への通信はありません。
- Chrome の設定画面など、拡張がページに入れない場所では、ドットは出ません。

## 構成

| ファイル | 役割 |
| --- | --- |
| `manifest.json` | Manifest V3 の定義 |
| `content.js` | ページ上でドットを描き、カーソルに追従させる |
| `defaults.js` | 設定の初期値と、保存データの整形(`content.js` と `popup.js` で共有) |
| `popup.html` / `popup.js` | 設定のポップアップ |
| `background.js` | インストール・更新の直後に、すでに開いているタブへ拡張を注入する(タブの再読み込みが要らなくなる) |
